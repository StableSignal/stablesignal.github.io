Delivery correction · 3 August 2026

The Arc testnet RPC does not currently authorize browser requests from the GitHub Pages origin. Pulse now captures the same bounded 20-block window during deployment and serves the verified JSON from its own origin. Captures are attempted periodically, the interface displays their observation time, and a failed or delayed capture leaves the prior successful deployment online.

Verification standard

The beta is considered ready when the production bundle loads at /pulse/, the latest published Arc testnet snapshot renders without browser RPC errors, wallet and contract explorer lookups return clear states, explorer links resolve safely in a new tab, and the interface remains usable on mobile and by keyboard.

Scope boundaries

Pulse is a testnet research interface, not a production monitor, indexer, finality oracle, wallet, custody service, transaction signer, risk rating, or statement about mainnet conditions. Displayed values can be affected by RPC availability, reorganizations, test activity, and observation-window selection.
